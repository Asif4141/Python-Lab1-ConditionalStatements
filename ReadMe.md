# Karabakh University - Fundamentals of Programming

## Laboratory Assignment 1: Conditional Statements and Decision-Making in Python

This repository contains the solutions for Laboratory Assignment 1 for the **"Introduction to Programming"** course, tailored for undergraduate students in Computer Engineering and Data Analytics at Garabagh University.

## 📁 Project Structure

The repository includes the following source code files and lab documentation:

* `BMI Calculator.py` – Calculates Body Mass Index (BMI) and determines the health category.
* `Chinese Zodiac Calculator.py` – Determines the Chinese Zodiac sign based on the user's birth year.
* `Birthday Guessing Game.py` – An interactive game guessing the day of birth using binary logic and predefined number sets.
* `FoP\_LAB\_01.docx` – Official lab report document.
* `README.md` – Project overview and instructions.

## 🚀 Tasks Overview

### Task 1: Body Mass Index (BMI) Calculator

Prompts the user to enter weight (in kilograms) and height (in meters), calculates the BMI value, and categorizes it as Underweight, Normal Weight, Overweight, or Obese.

* **Formula:** $\\text{BMI} = \\frac{\\text{weight}}{\\text{height}^2}$

### Task 2: Chinese Zodiac Calculator

Determines the user's Chinese Zodiac animal using the remainder of the birth year divided by 12 ($year \\pmod{12}$).

### Task 3: Birthday Guessing Game

Displays five sets of numbers and asks whether the user's birthday appears in each set (`1` for Yes, `0` for No). It then calculates and displays the exact birth date using the answers provided.

## ⚙️ How to Run

Ensure Python is installed on your system. You can execute the scripts using terminal/command prompt or any Python IDE (e.g., VS Code, PyCharm):

```bash
python "BMI Calculator.py"
python "Chinese Zodiac Calculator.py"
python "Birthday Guessing Game.py"
```
